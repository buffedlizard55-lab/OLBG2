Repository review

A line-by-line pass over the merged repository before this layer was added. 7 findings, each one reproducible from the evidence column. None of them is repaired silently: files owned by other sessions are left alone and the finding is recorded here.

RR-01Unresolved merge-conflict markers are checked in
`COORDINATION.md` carries 3 closing conflict markers and `METHODOLOGY.md` carries 1. They are plain text, so nothing breaks, but they are not content and they make the shared board hard to read.mediumRR-02Thirty-three published dashboards overlap the same brief
Each of these directories publishes a full dashboard for the same 15-sport brief, with different counts and different levels of evidence. There is no marker of which one is authoritative, so a reader landing on any of them can be misled.highRR-03The root dashboard advertises a stale snapshot and points at the weakest desk
The root page's status stripe still reads 2026-10-22 08:15 UTC and its primary call to action opens `/monitor/`, which states that no high-confidence picks cleared. The most complete desk from the same day, `/signal/`, is not linked from the root navigation at all.highRR-04The cross-layer link checker trips over any non-UTF-8 file
`scripts/integration_audit.py` reads every `*.html` under the repository as UTF-8 with no fallback. A single Latin-1 response stored under `data/` was enough to raise UnicodeDecodeError and fail the whole suite. Captures in this layer are therefore stored as `.txt`, and the checker itself is left untouched as another session's file.mediumRR-05Duplicate element ids in a published page
Anchor targets repeat inside the page, so a fragment link can land on the wrong row.lowRR-06CI rebuilds many layers and checks them for drift
The Pages workflow rebuilds 53 test modules' worth of layers and fails if generated HTML differs from what is committed. Any new layer has to be added to both the rebuild steps and the drift list or it will silently rot. This layer adds its own step and drift paths.infoRR-07Earlier desks publish numbers that cannot be reconciled with each other
For the same day the repository contains, among others, 101 fixtures (/signal/), 133 (/liveboard/), 24 (/monitor/), 40 (/focus/) and 188 stored rows on the root. They describe different capture windows rather than contradicting one another, but the pages do not say so consistently.medium
