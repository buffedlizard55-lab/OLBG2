What this console found

1 · The catalogue is 91% duplication

1,619 published rows resolve to 433 distinct fixtures. 1,466 rows sit in 369 fixtures published by two or more layers. See overlaps →

2 · 64 rows are not matches

Outright futures, tournament fields, “field v venue” and greyhound race cards are formatted as head-to-head fixtures with their own moneylines. List them →

3 · The same team is priced 341 times differently

Largest disagreement: see the conflicts page. Different layers run different models and nothing reconciles them, so two URLs can quote the same club at very different prices. Compare →

4 · 116 grades break the project's own rule

The published rule is “high only when p ≥ 0.70 and the fair price is inside −250…+10000”. Violations are listed row by row. Check grades →

How to read this

This page does not declare any other layer “wrong”. Two layers disagreeing about a price is expected when each runs its own model; what is not acceptable is publishing both as if each were the authoritative number. The console measures that gap, names the rows, and leaves the decision visible. Values are machine-derived from the committed JSON, so every finding can be reproduced by running python3 scripts/reconcile_audit.py.
