How the independent re-check works

Everything here is recomputed from the checked-in files by two short scripts. No external page is opened and no value is inferred: when a rule cannot be checked from the checkout, the limit is published instead.

The nine check classes

  • C1 Scope and counts. The sport list must be exactly the fifteen requested sports, and every published count field must equal the length of its row list.
  • C2 Provenance. Every fixture carries an https official link and one or more sourced facts; each fact needs an https link, a source key that exists in the register, a non-empty value and a capture time.
  • C3 Price arithmetic. For a probability p the American price is -100·p/(1-p) when p ≥ 0.5 and 100·(1-p)/p otherwise, rounded to whole cents with a 100 floor. The decimal price must equal round(1/p, 3). The band flag is true exactly when the American price is between −250 and +10000 inclusive.
  • C4 Grades and scores. A result selection grades high only at 62% or more on a goals-or-points pricing family with quality at least 0.85; 55% grades medium; total markets and the evidence-ladder family are capped at medium; anything out of band is low. The 0-10 score is ten times the probability, shaded 0.8 for ladder-built prices, rounded to one decimal. Each pick is joined back to its full price row before re-grading.
  • C5 Written predictions. Minimum 30 words with the stored word count matching the actual count; unique body text and unique five-word openings; the selection's longest words must appear in the prose; at least two sourced facts; the id derives from the fixture id; the two internal-only reserved words never appear; every pre-game high or medium pick must have a preview.
  • C6 Rendering. Primary tables render exactly as many rows as the data holds and every table row cites an https source; prediction cards match the preview count; the front door shows the headline totals; every internal link and anchor resolves.
  • C7 OLBG linkage. Each captured listing has a numeric event id and an https URL; fixtures that record an event URL must resolve to a captured listing. Fixtures marked listed without a URL become observations, not silent passes.
  • C8 Source register. Every (source key, URL) pair is unique and https-only with a capture time; the host census feeds the live re-read block register.
  • C9 Review flags. The underlying desk's flag list reconciles by severity and each item carries an id, detail and source link.

Reproduce it

  • python scripts/recheck_audit.py — re-runs every check and writes data/recheck/results.json.
  • python scripts/recheck_build.py — renders these pages.
  • python scripts/recheck_verify.py — rebuilds both and fails on any byte change or failed rule.
  • python -m unittest tests.test_recheck_26707f98 — the test module for this desk.

What is deliberately not claimed

  • That any external page currently shows the captured value — the environment cannot open those pages.
  • That the originated prices are independent of OLBG on quoted-market rows — the underlying desk documents that one side per event is all OLBG exposes, and no second source is reachable here.
  • Any news, injury or line-up change after the 17:35 UTC capture — none is available in the checkout.
