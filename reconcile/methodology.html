Method

The audit is deterministic and reproduces exactly from committed JSON. No network call, no clock, no randomness, no hand-entered number.

Pipeline

  • python3 scripts/reconcile_audit.py — reads the eleven published layers, normalises each row, and writes data/reconcile/rows.json and data/reconcile/report.json.
  • python3 scripts/reconcile_build.py — renders this console from those two files plus the hand-read data/reconcile/spot_checks.json.
  • python3 scripts/reconcile_verify.py — structural gate: every listed row keeps a source link, every internal link resolves, no upstream data file changed, published counts match the report.
  • python3 -m unittest tests.test_reconcile — unit tests over the normaliser, the classifier and the report.

Normalisation

The layers publish five different market shapes (flat selection lists, per-market dicts with outcomes, home/away dicts, winner/handicap/total objects, and survey lines keyed by side_a/side_b). Each is parsed into one record: sport slug, date, home/away (club codes expanded from the repository's own captured team tables), moneyline decimals and probabilities mapped by team name, pick, grade, source URL, and the layer's own capture stamp.

A fixture's identity is (sport, date, sorted team names) after accent stripping, alias resolution and parenthetical removal. That is deliberately strict: two rows only merge when they describe the same two clubs on the same date.

Limits, stated plainly

  • Only nine claims were re-read from an official page (spot-checks page). The rest of the audit is mechanical, so it can prove inconsistency between layers but not that any single layer matches the outside world.
  • “Non-fixture” is a classification from the row's own text and structure. It is a defect report, not a deletion.
  • Price and grade conflicts are expected when layers run independent models. The finding is that no reconciliation exists, not that a specific model is wrong.
  • The audit date is fixed at 2026-10-22 so rebuilds are reproducible; it is not read from the clock.
