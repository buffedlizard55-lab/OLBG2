RR-04The cross-layer link checker trips over any non-UTF-8 file
`scripts/integration_audit.py` reads every `*.html` under the repository as UTF-8 with no fallback. A single Latin-1 response stored under `data/` was enough to raise UnicodeDecodeError and fail the whole suite. Captures in this layer are therefore stored as `.txt`, and the checker itself is left untouched as another session's file.		mediumReproduced locally: `python3 -m unittest tests.test_integration` failed with UnicodeDecodeError at `scripts/integration_audit.py:127` while `data/ledger/raw/handball_spain.html` existed.

RR-06CI rebuilds many layers and checks them for drift
The Pages workflow rebuilds 46 test modules' worth of layers and fails if generated HTML differs from what is committed. Any new layer has to be added to both the rebuild steps and the drift list or it will silently rot. This layer adds its own step and drift paths.		info.github/workflows/pages.yml — 'Fail if any generated page or data file is stale'
