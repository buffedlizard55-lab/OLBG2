Flagged for review

These known gaps are shown plainly rather than filled with guesses. A flag is a limitation in this repository, not a claim that no match, market, or source exists.

01

Full sport and competition taxonomy is not yet audited

OLBG's public tips page describes coverage across “20+ sports,” while this repository only records five example categories seen in the fetched page. The full menu, event coverage, and exclusions have not been exhaustively enumerated. Category observation is not event verification.

Reference: OLBG public tips listing ↗ · First-party site reference only
02

No current fixtures verified against official event sources

The repository began without fixture data. No league, governing-body, event, team, or athlete schedule has been checked for a complete current slate. All fixture tables therefore remain empty; “empty” does not mean “no events.”

Official event sources: not yet identified or checked; no fixture claims published.
03

No original betting lines or pricing method established

No repeatable model, input dataset, settlement definitions, timestamp protocol, or validation/calibration record exists yet. Publishing a winner line, handicap, or total would be unsupported. OLBG market labels are not our lines.

Market terminology reference: OLBG public tips listing ↗ · Not an official event source or price source
04

No confidence ratings or high-confidence predictions issued

There are no official-source-verified recent results/form notes or documented confidence calibration. No match winner is selected. Unique 30+ word prediction copy should be written only after team/player, current form, recent history, and selection are all directly supported.

No prediction facts or recommendation published.
05

Sport exclusion terminology and refresh cadence need review

The requested exclusions include “soccer,” “football,” “American football,” and “hurling.” The public OLBG listing displayed “Gaelic Football”; whether this fits the intended scope is ambiguous, so it is separately tagged for review and no fixture content is included. No recurring source refresh process is configured.

Reference: OLBG public tips listing ↗ · Scope interpretation remains unverified

How flags are cleared

Add the official source URL, record the specific fact it confirms, note the check date/time, and preserve any unresolved conflicts. Then update the relevant category page and this log. Do not clear a flag solely because a value appears on OLBG or another secondary listing.
