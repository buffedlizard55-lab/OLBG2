METHOD

How a line is originated

Full methodology →

1. Official inputs

Goals for and against per game, power play, penalty kill and the last ten results for both teams, read from the NHL game-centre payload at 2026-10-21T05:52:00Z.

2. Poisson score matrix

Each attack is blended with the opposing defence and run through a 60-minute Poisson matrix. Ties are split 50/50 for the two-way money line.

3. Fair price and confidence

Prices are 1 / probability. Confidence is set by the distance of the selection from a coin flip, using the thresholds declared in the data file.
