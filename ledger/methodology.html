Method

1. What the desk collects

The slate is OLBG's: every upcoming event in the fifteen requested sports at capture time. The verification and the numbers are ours. OLBG's quoted price is carried in its own column and never used to build a price of ours.

2. How a price is originated

Only official season records are inputs: wins, losses, goals or points for and against, games played. From them:

rating      = 1500 + 400 × (points_pct − 0.5) + 30 × (score_difference_per_game)
home edge   = +45 rating points
p(home)     = 1 / (1 + 10^(−((rating_home + 45) − rating_away) / 400))
expected    = attack_home × defence_away ÷ league_average   (and the mirror for the away side)
total       = Poisson over the two expected scores (normal approximation above 30 combined points)
handicap    = the same distribution, ±1.5 for the side we make favourite

The fair decimal is 1/p. No margin is added and no bookmaker price is an input. The expected score behind every fixture is printed on Fixtures & prices so the arithmetic can be checked.

3. Confidence

high = 70% or better, medium = 60–69.9%, low = below 60%. The same thresholds apply to a market-implied price, which is labelled separately because it is not our number.

4. The price band

The brief asks for selections between −250 and +10000 and for a chance above 70%. A 70% chance is −233, so the two rules only overlap between 70.0% and 71.4%. The desk publishes the intersection honestly: 149 high-confidence selections, 11 of them inside the band.

5. What is never done

  • A missing value is left blank, never filled from another sport, another day or an average.
  • No injury, suspension or team-news claim is made without an official page that says it.
  • No preview is written for a fixture without a captured fact to write around. Eleven sports therefore have none today.
  • The words "model" and "verified" do not appear in a published preview; the method is described here instead.

6. Reproducing this

python3 scripts/ledger_capture.py      # on a runner with internet access
python3 scripts/ledger_seed.py         # OLBG payload -> data/ledger/olbg.json
python3 scripts/ledger_official.py     # official payloads -> data/ledger/official.json
python3 scripts/ledger_merge.py        # match OLBG events to official sources
python3 scripts/ledger_model.py        # originate prices
python3 scripts/ledger_picks.py        # grade and rank selections
python3 scripts/ledger_predictions.py  # validate the written previews
python3 scripts/ledger_report.py       # sources, flags, repository review
python3 scripts/ledger_build.py        # this site
python3 scripts/ledger_verify.py       # audit the result
